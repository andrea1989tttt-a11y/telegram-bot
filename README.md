# Музыкальный помощник — Telegram-бот

Бот помогает ученику **3 класса** музыкальной школы повторять нотную грамоту, ритм и музыкальные термины между занятиями.

Ориентир по уровню: рабочая тетрадь Г. Ф. Калининой «Сольфеджио. 3 класс».  
Задания в боте **свои**, это не копия учебника. Подробности — в `SOURCES.md` и `BRIEF.md`.

## 1. Создать бота в Telegram (BotFather)

1. Откройте Telegram и найдите **@BotFather**.
2. Нажмите **Start**.
3. Отправьте команду `/newbot`.
4. Придумайте имя бота (например: `Музыкальный помощник`).
5. Придумайте username, он должен заканчиваться на `bot` (например: `pavel_music_helper_bot`).
6. BotFather пришлёт **токен**. Скопируйте его в надёжное место.
7. **Не** вставляйте токен в чаты, скриншоты и GitHub.

---

## 2. Открыть проект в GitHub Desktop

1. Установите [GitHub Desktop](https://desktop.github.com/), если его ещё нет.
2. Меню **File → Add Local Repository…**
3. Укажите папку этого проекта (`telegram bot`).
4. Если GitHub Desktop предложит создать репозиторий — подтвердите.
5. Перед публикацией убедитесь, что файл `.env` **не** в списке изменений (он в `.gitignore`).

Публиковать репозиторий и включать платные услуги нужно только с согласия владельца проекта.

---

## 3. Указать токен локально

1. Скопируйте файл `.env.example` и назовите копию `.env`.
2. Откройте `.env` в текстовом редакторе.
3. Замените `вставьте_токен_сюда` на токен от BotFather.
4. Сохраните файл.

Пример содержимого:

```
BOT_TOKEN=123456:ABCDEF_пример_не_настоящий
```

---

## 4. Запуск на компьютере (для проверки)

Нужен установленный **Node.js** (версия 18 или новее).

В Cursor / VS Code откройте терминал в папке проекта и выполните:

```bash
npm install
npm start
```

Проверка банка вопросов без Telegram:

```bash
npm run check
```

Затем в Telegram найдите своего бота и нажмите **Start**.

Остановка: в терминале `Ctrl+C`.

## 5. Размещение на Timeweb Cloud

Условия и стоимость тарифов проверяйте на сайте Timeweb **до** оплаты. Платные действия — только с согласия владельца.

Общий порядок через панель (без привязки к конкретной кнопке тарифа):

1. Войдите в панель Timeweb Cloud.
2. Создайте подходящий сервис для Node.js-приложения (облачный сервер или приложение — по вашей инструкции хостинга).
3. Загрузите файлы проекта **без** `.env` и **без** `node_modules` (или подключите Git-репозиторий).
4. В настройках окружения добавьте переменную:
   - имя: `BOT_TOKEN`
   - значение: токен от BotFather
5. Укажите команду запуска: `npm install && npm start`  
   (или раздельно: сначала установка зависимостей, затем `npm start` — как принято в выбранном тарифе).
6. Убедитесь, что приложение запущено постоянно (не выключается сразу после старта).
7. Проверьте бота в Telegram.

Если хостинг требует открытый порт для webhook — в первой версии бот работает через **long polling** (`bot.launch()`), отдельный домен не обязателен. Для webhook понадобится доработка — это отдельный шаг.

## 6. Как пользоваться ботом

1. `/start` — приветствие и меню.
2. Выберите раздел: повторение 1–2 класса, нотная грамота, ритм, термины или смешанная тренировка.
3. Откройте тему → прочитайте объяснение → **Потренироваться**.
4. Ответьте на 5 вопросов кнопками.
5. После каждого ответа будет короткое объяснение.
6. В конце: результат `N из 5`, кнопки **Повторить тему**, **Ещё задания**, **В меню**.

Диалоги разных пользователей не смешиваются.  
После перезапуска сервера прогресс сбрасывается — нужно начать новую тренировку.

## 7. Как добавлять темы и задания

### Новая тема

1. Добавьте описание в `src/content/topics.js` в объект `TOPICS`.
2. Впишите id темы в нужную секцию в `SECTIONS`.

### Новые вопросы

1. Откройте `src/content/questions.js`.
2. Добавьте объект вопроса:

```js
{
  id: 'dur_11',
  topicId: 'durations',
  text: 'Текст вопроса?',
  options: ['Вариант А', 'Вариант Б', 'Вариант В'],
  correctIndex: 1, // номер правильного с нуля
  explainCorrect: 'Коротко, почему верно.',
  explainWrong: 'Спокойное объяснение правильного ответа.',
}
```

3. Для смешанной тренировки при желании добавьте id в `MIXED_QUESTION_IDS`.
4. Запустите `npm run check`.
5. Перезапустите бота.

Не копируйте дословно задания из учебника.

## 8. Проверка готовности

| Критерий | Статус |
| --- | --- |
| Меню и кнопки переходов | Реализовано в коде |
| Объяснения тем | Есть, ориентир — 3 класс |
| Тренировки по 5 вопросов | Да |
| Объяснение после ответа | Да |
| Итог `N из 5` | Да |
| Вопросы не повторяются внутри одной тренировки | Да |
| «Ещё задания» берёт непройденные | Да |
| Если задания закончились — сообщение и повтор | Да |
| Диалоги пользователей разделены | Да (память процесса) |
| Возврат в меню завершает тренировку | Да |
| Токен не в коде | Да (только `.env`) |
| Нотные изображения | Пока нет — задания текстом |
| Проверка в живом Telegram | Нужен ваш токен и запуск |
| Публикация на Timeweb | Не выполнялась без согласия |

---

## Безопасность

- Токен храните только в переменных окружения (`.env` или панель хостинга).
- Не коммитьте `.env`.
- Бот не спрашивает фамилию, школу, адрес и другие лишние данные.
- В сообщениях об ошибках токен не выводится.
